# Local PDF CBT — Idea Parking

- 기준일: 2026-09-03
- 문서 버전: `0.2.7`
- 상태: 미래 검토 목록과 채택 이력. **IDEA-029는 Unit 1.5, IDEA-030은 Unit 1.6, IDEA-031은 사용자의 명시적 요청으로 Unit 2.7에 채택했으며, 나머지 항목은 현재 구현 승인을 의미하지 않는다.**
- 기준: [PROJECT_BIBLE](PROJECT_BIBLE.md), 단계별 일정: [ROADMAP](ROADMAP.md)

## 사용 규칙

여기는 첫 MVP 범위에 넣지 않을 아이디어와 확장 시 검토할 질문을 보관한다. ROADMAP에 들어 있는 항목도 여전히 미착수이며, 이 문서에 있다는 이유로 관련 의존성·테이블·버튼·빈 모듈을 만들지 않는다.

채택하려면 사용자 가치, 선행 조건, 데이터/보안 영향, 검증 방법을 정하고 해당 Phase의 작은 Unit으로 옮긴다. 중복 아이디어는 합치며 보류 이유와 재검토 조건을 남긴다.

## 현재 의도적으로 채택하지 않는 방향

- 계정 가입, 클라우드 동기화, 서버 업로드를 기본 사용 조건으로 만들지 않는다.
- PDF 원본에 마스크를 영구 삽입하거나 답을 삭제하는 편집 기능은 현재 제품 목적이 아니다.
- 시험 부정행위 방지, 화면 캡처 차단, DRM은 단순 학습용 가림과 별개의 제품 범위다.
- 객관식 복수 정답·주관식·서술형 채점은 첫 MVP에 추가하지 않는다.
- 모든 형식 자동 지원이나 완벽한 OCR/AI 정답 판단을 약속하지 않는다.

새 아이디어가 핵심 원칙과 충돌하면 구현보다 먼저 [DECISIONS](DECISIONS.md)에 판단 근거와 필요한 범위 변경을 기록한다.
